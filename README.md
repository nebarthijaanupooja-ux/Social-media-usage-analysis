# Social Media Usage Analysis

## 📊 Project Overview

This project was developed as part of my APSSDC Summer Internship.

The project focuses on analyzing social media usage data using Python. The dataset contains information about users and their social media usage patterns. Data analysis techniques were applied to identify patterns and generate meaningful insights.

## 🎯 Objectives

- Analyze social media user data
- Perform data cleaning and preprocessing
- Explore user lifestyle and social media usage patterns
- Identify meaningful patterns from the dataset
- Generate insights using Python

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- CSV Dataset

## 📂 Project Files

- `Social_Media_Usage_Analysis.ipynb` – Python/Jupyter Notebook containing the complete analysis
- `instagram_users_lifestyle.csv` – Dataset used for the analysis
- `DA PROJECT DOC.pdf` – Project documentation
- `DA Project ppt (1).pptx` – Project presentation

## 🔍 Analysis

The project includes data loading, data exploration, preprocessing, analysis and visualization of social media usage data using Python.
